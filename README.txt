SO Aim Assistant — mobile manual edition
Deploy: upload this folder to a GitHub repository and import it into Vercel as an Other/static project. No build command needed. Alternatively unzip and upload the folder with Vercel CLI.
IMPORTANT: The original PC shot formulas were not available. Results use placeholder approximations, and should NOT be treated as verified Shot Online shot calculations. Replace the render() calculations in script.js with original formulas when available.
No capture functions. Works offline after first visit on supported browsers.
